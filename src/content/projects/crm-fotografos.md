Desenvolvimento da arquitetura de frontend, backend e banco de dados para suportar o fluxo completo de um estúdio fotográfico, desde o primeiro contato do cliente até o faturamento.

A stack foi pensada para alta performance, utilizando FastAPI para as regras de negócio complexas do backend e PostgreSQL para modelagem relacional eficiente e políticas de segurança em nível de linha (RLS).
